# Prodigy Infotech - Data Science Task 5

## Objective

Analyze traffic accident data to identify patterns related to time, weather, road conditions, severity, location, and contributing factors.

## Dataset

A small 49-record educational traffic accident dataset was used for this task.

The dataset contains information about:

- Date
- Time
- Borough
- Weather
- Road condition
- Accident severity
- Contributing factor
- Latitude
- Longitude

## Tools Used

- Python
- Pandas
- Matplotlib
- VS Code

## Data Analysis

The following analyses were performed:

- Accidents by time of day
- Accidents by weather
- Accidents by road condition
- Accident severity
- Accidents by borough
- Contributing factors

## Visualizations

The project includes the following visualizations:

- Traffic accidents by time of day
- Traffic accidents by weather
- Traffic accidents by road condition
- Traffic accident severity
- Traffic accidents by borough
- Contributing factors

## Key Findings

The analysis was used to identify patterns in traffic accidents based on time, weather, road conditions, severity, location, and contributing factors.

## Conclusion

This project demonstrates how Python, Pandas, and Matplotlib can be used to clean, analyze, and visualize traffic accident data.

The visualizations make it easier to understand accident patterns and identify factors that may be associated with traffic accidents.

## Important Note

This is a small educational dataset created for demonstration and learning purposes. The results should not be interpreted as official NYC-wide traffic accident statistics.
