# Prodigy Infotech - Data Science Task 1

## Task Objective

Create a bar chart or histogram to visualize the distribution of a categorical or continuous variable.

## Dataset

For this task, I used a population dataset containing population information for different countries.

## Task Performed

I created a histogram to visualize the distribution of population across countries for the year 2024.

## Technologies Used

- Python
- Pandas
- Matplotlib
- VS Code

## Visualization

The histogram shows how population is distributed across different countries.

## Key Observation

The population distribution is highly uneven. Most countries have comparatively smaller populations, while a small number of countries have very large populations.

This task provided practical experience in reading a dataset, selecting a continuous variable, and using a histogram to visualize its distribution using Python and Matplotlib.
